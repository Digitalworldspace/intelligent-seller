દરેક લિંકમાં તમારું ID છે કે નહીં
કમિશન તમારા ખાતામાં કેવી રીતે આવે
  1. ગ્રાહક આ સાઇટ પરના બટનથી Amazon / Flipkart / બીજી સાઇટ પર જાય છે. લિંકમાં તમારું affiliate ID હોય છે.
  2. પ્લેટફોર્મ એ ગ્રાહકની ખરીદી તમારા ID સાથે નોંધે છે (cookie દ્વારા, થોડા સમય માટે).
  3. ઓર્ડર ડિલિવર થાય અને રિટર્ન સમય પૂરો થાય પછી કમિશન તમારા affiliate ડેશબોર્ડમાં "confirmed" થાય છે.
  4. પ્લેટફોર્મ તેના નિયમ પ્રમાણે (સામાન્ય રીતે મહિને એક વાર, ઓછામાં ઓછી રકમ થયા પછી) તમારા બેંક ખાતામાં પૈસા મોકલે છે. બેંક ખાતું અને PAN affiliate એકાઉન્ટમાં ઉમેરવા જરૂરી છે.
